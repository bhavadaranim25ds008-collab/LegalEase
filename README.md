# LegalEase

LegalEase is an AI-powered legal assistant built with Python. It uses an AI core to help users understand and work with legal information through a simple web interface.

## Project Structure
- `ai_core/` - AI logic and processing
- `legalEaseAPI/` - Backend API
- `frontend/` - User interface
- `docs/` - Documentation
- `Image/` - Images and logos

## Setup
1. Clone the repository
2. Create a virtual environment: `python -m venv venv`
3. Install dependencies: `pip install -r requirements.txt`
4. Create a `.env` file and add your own API key
5. Run the project: `bash run.sh`
